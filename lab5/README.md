Сравнение методов вычисления факториала с мемоизацией
Описание проекта
Сравнительный анализ производительности различных методов вычисления факториала с использованием мемоизации и без неё. Проект включает четыре реализации, тесты производительности и визуализацию результатов.

Быстрый старт
Установка
bash
pip install matplotlib
Запуск
bash
python prog_lab3.py
Тестирование
bash
python -m unittest test_prog_lab3.py
Реализации методов
Рекурсивные методы
python
def fact_recursive(n: int) -> int:
    if n == 0:
        return 1
    return n * fact_recursive(n - 1)

@lru_cache(maxsize=None)
def fact_recursive_cached(n: int) -> int:
    if n == 0:
        return 1
    return n * fact_recursive_cached(n - 1)
Итеративные методы
python
def fact_iterative(n: int) -> int:
    res = 1
    for i in range(1, n + 1):
        res *= i
    return res

@lru_cache(maxsize=None)
def fact_iterative_cached(n: int) -> int:
    res = 1
    for i in range(1, n + 1):
        res *= i
    return res
Результаты
Проект генерирует график сравнения времени выполнения методов для значений n от 10 до 90.

Ключевые выводы
Рекурсивный метод без кэша - самый медленный

Мемоизация значительно ускоряет рекурсивные вычисления

Итеративные методы показывают стабильную производительность

Кэширование эффективно при повторных вызовах

Заключение
Мемоизация делает рекурсивные методы конкурентоспособными с итеративными, а для повторяющихся вычислений кэширование рекомендуется для оптимизации производительности.
