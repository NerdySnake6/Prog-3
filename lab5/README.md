Сравнение методов вычисления факториала с мемоизацией
Этот проект сравнивает производительность различных методов вычисления факториала с использованием мемоизации и без неё.

Описание
Проект включает в себя:

Четыре реализации вычисления факториала:

Рекурсивный метод без кэширования

Рекурсивный метод с кэшированием (мемоизация)

Итеративный метод без кэширования

Итеративный метод с кэшированием (мемоизация)

Тесты производительности для сравнения времени выполнения

Визуализацию результатов в виде графика

Модульные тесты для проверки корректности вычислений 

Реализации методов
1. Рекурсивный метод без мемоизации
python
def fact_recursive(n: int) -> int:
    if n == 0:
        return 1
    return n * fact_recursive(n - 1)
2. Рекурсивный метод с мемоизацией
python
@lru_cache(maxsize=None)
def fact_recursive_cached(n: int) -> int:
    if n == 0:
        return 1
    return n * fact_recursive_cached(n - 1)
3. Итеративный метод без мемоизации
python
def fact_iterative(n: int) -> int:
    res = 1
    for i in range(1, n + 1):
        res *= i
    return res
4. Итеративный метод с мемоизацией
python
@lru_cache(maxsize=None)
def fact_iterative_cached(n: int) -> int:
    res = 1
    for i in range(1, n + 1):
        res *= i
    return res
Функция тестирования производительности
python
def benchmark(func, n, number=1000, repeat=3):
    """Возвращает минимальное время выполнения func(n)"""
    times = timeit.repeat(lambda: func(n), number=number, repeat=repeat)
    return min(times)
Модульные тесты
Тесты проверяют:

Корректность вычисления факториала для всех методов

Согласованность результатов между разными методами

Работу механизма кэширования

python
class TestFactorial(unittest.TestCase):
    def test_fact_recursive(self):
        self.assertEqual(fact_recursive(0), 1)
        self.assertEqual(fact_recursive(1), 1)
        self.assertEqual(fact_recursive(5), 120)

    def test_all_same_results(self):
        self.assertEqual(fact_recursive(10), fact_recursive_cached(10))
        self.assertEqual(fact_recursive(10), fact_iterative(10))
        self.assertEqual(fact_recursive(10), fact_iterative_cached(10))

        Ключевые наблюдения
Рекурсивный метод без кэша - самый медленный, особенно для больших значений n

Рекурсивный метод с кэшем - значительно быстрее рекурсивного без кэша благодаря мемоизации

Итеративный метод без кэша - эффективный и стабильный

Итеративный метод с кэшем - показывает наилучшую производительность при повторных вызовах

Заключение Мемоизация значительно ускоряет рекурсивные вычисления, делая их конкурентоспособными с итеративными методами. 
Для задач с повторными вычислениями одних и тех же значений использование кэширования рекомендуется для оптимизации производительности. 
Итеративные методы в целом показывают более стабильную производительность, особенно для больших значений n.
