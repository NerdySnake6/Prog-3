# Лабораторная работа: Two Sum

## Цель работы
Реализация алгоритма для поиска индексов двух чисел в массиве, сумма которых равна заданному значению.

## Описание задачи
Дан массив целых чисел `nums` и целочисленное значение `target`. Необходимо найти индексы двух чисел таким образом, чтобы их сумма равнялась `target`. 

**Ограничения:**
- Нельзя использовать один и тот же элемент дважды
- Можно вернуть ответ в любом порядке
- Гарантируется, что существует не более одного решения
  
### Алгоритм
Используется хэш-таблица для хранения чисел и их индексов. Для каждого элемента вычисляется complement (разность между target и текущим числом). Если complement уже есть в хэш-таблице, возвращаются индексы обоих чисел.

### Сложность
- **Время:** O(n) - один проход по массиву
- **Пространство:** O(n) - хранение элементов в хэш-таблице
