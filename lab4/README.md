# Генератор бинарного дерева

## Описание проекта
Реализация нерекурсивного генератора бинарного дерева с использованием очереди. Проект включает функцию генерации дерева и модульные тесты для проверки корректности работы.

## Быстрый старт

### Запуск генератора
```bash
python lab_4_bin_tree.py
```

### Запуск тестов
```bash
python -m unittest unittest_lab_4.py
```

## Функция генерации

### `gen_bin_tree(height=4, root=3, left_branch=None, right_branch=None)`
Генерирует бинарное дерево заданной высоты без использования рекурсии.

**Параметры:**
- `height` - высота дерева (по умолчанию 4)
- `root` - значение корневого узла (по умолчанию 3)
- `left_branch` - функция для вычисления левого потомка (по умолчанию x+2)
- `right_branch` - функция для вычисления правого потомка (по умолчанию x*3)

**Возвращает:**
- Словарь, представляющий бинарное дерево

## Пример использования
```python
tree = gen_bin_tree(height=4, root=3)
print(tree)
```

## Тестирование
Модульные тесты проверяют:
- Генерацию дерева с параметрами по умолчанию
- Создание дерева небольшой высоты
- Генерацию дерева только с корнем
- Создание пустого дерева

## Особенности реализации
- Используется очередь (`deque`) для обхода уровней дерева
- Отсутствует рекурсия, что предотвращает проблемы с глубиной рекурсии
- Гибкая настройка правил генерации потомков через lambda-функции
