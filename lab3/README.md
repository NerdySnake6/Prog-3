# Лабораторная работа 3: Бинарное дерево

## Задание
Рекурсивное построение бинарного дерева с возможностью задания пользовательских алгоритмов вычисления потомков.

## Реализация
Функция `gen_bin_tree()` принимает следующие параметры:
- `height` - высота дерева
- `root` - значение корневого узла  
- `left_leaf` - функция для вычисления левого потомка (по умолчанию: root + 2)
- `right_leaf` - функция для вычисления правого потомка (по умолчанию: root * 3)

Особенности реализации:
- Поддерживаются lambda-функции для вычисления потомков
- Обработка некорректных значений высоты (выбрасывается ValueError)
- Дерево высотой 0 возвращает None
- Рекурсивный алгоритм построения
