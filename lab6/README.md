# Курсы валют ЦБ РФ

Проект содержит 3 версии функции получения курсов валют с улучшением архитектуры и логирования.

Установка: `pip install requests`

Файлы проекта:
- Lab_it1.py - базовая версия с обработкой ошибок в stdout
- Lab_it2.py - логирование вынесено в декоратор
- Lab_it3.py - профессиональное логирование через модуль logging
- test_lab1.py, test_lab2.py, test_lab3.py - тесты для каждой версии
- test_all.py - запуск всех тестов

Запуск тестов: `python test_all.py`

Функция get_currencies() получает актуальные курсы валют через API ЦБ РФ. Принимает список кодов валют (USD, EUR и т.д.) и возвращает словарь с курсами или None при ошибке. Обрабатывает проблемы сети, отсутствие валют и невалидные данные.
